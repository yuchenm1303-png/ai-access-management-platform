# AccessFlow

一个用于演示“用户订单、租期、会话状态和管理员操作”的静态网页 MVP。

## 当前版本

- 管理端总览
- 订单创建、搜索、开通、暂停、恢复、延期和到期状态
- 待处理登录任务
- 受控浏览器会话列表、接管登录占位、销毁会话
- 用户端套餐、租期倒计时、续费申请和使用入口
- 使用 `localStorage` 保存演示数据
- 响应式布局，支持电脑和手机浏览

## 运行方式

直接用浏览器打开 `index.html`，或使用任意静态文件服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 重要边界

该仓库当前仅为前端交互原型，不包含：

- 真实支付
- 真实用户认证
- 密码、验证码、Cookie 或会话令牌采集
- 远程浏览器或云桌面服务
- 对第三方网站登录流程的自动化

管理员登录区域仅作为未来“受控远程浏览器”服务的界面占位。

## 后续技术路线

1. 改造成 Next.js + TypeScript 项目。
2. 接入 PostgreSQL，建立用户、订单、套餐、账号池、会话和操作日志数据表。
3. 增加管理员与用户身份认证。
4. 增加定时任务，自动处理到期停用和提醒。
5. 对接受控的远程浏览器服务，仅向用户传输画面和输入，不向前端暴露登录凭据。
6. 部署到云服务器，并接入 HTTPS、审计日志、限流和备份。
